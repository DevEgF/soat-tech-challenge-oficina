4. Arquitetura proposta

Ver diagrama Mermaid completo no README.md raiz (seção "Fase 2 — Infraestrutura, escalabilidade e automação"). Resumo dos componentes:

  • Aplicação: Spring Boot (Kotlin), Clean Architecture, empacotada em imagem Docker multi-stage.
  • Orquestração: Kubernetes — Deployment da aplicação e do banco, Service, ConfigMap/Secret para configuração e credenciais, HorizontalPodAutoscaler escalando 1–5 réplicas por CPU/memória.
  • Infraestrutura como código: Terraform provisiona o cluster (kind) e aplica os manifestos do namespace, do banco e da aplicação.
  • CI/CD: GitHub Actions — build + testes (gate de cobertura JaCoCo) → build/push da imagem Docker → provisiona cluster efêmero → aplica manifestos K8s (banco + app) → smoke test.
